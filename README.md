## `ls projects/` — built in the open

### [go-mink](https://github.com/AshkanYarmoradi/go-mink)

**History is a feature.** An event-sourcing and CQRS toolkit for Go, with PostgreSQL and in-memory adapters, aggregates, and projections.

`Go` · `Event sourcing` · `CQRS` · **Creator & maintainer** · [Documentation ↗](https://go-mink.dev)

### [go-llama.cpp](https://github.com/AshkanYarmoradi/go-llama.cpp)

**Inference, closer to the metal.** Go bindings for local model inference with llama.cpp. A maintained fork of [go-skynet/go-llama.cpp](https://github.com/go-skynet/go-llama.cpp), connecting Go applications to a native engine through cgo.

`Go` · `C++ / cgo` · `Local AI` · **Maintainer of an upstream fork**

### [go-invoice-ninja](https://github.com/AshkanYarmoradi/go-invoice-ninja)

**Make the integration less interesting.** An unofficial Go client for the Invoice Ninja API, with typed interfaces, context-aware requests, retries, and rate-limit support.

`Go` · `API design` · `Integrations` · **Creator & maintainer**
